# Лабораторная работа 1: Классы — Реализация объектной модели данных и unit-тестов

## Описание предметной области

Реализована объектная модель для **риэлторского агентства**, в которой присутствуют три основных сущности:

- **Контрагент (`Client`)** — эта сущность характеризуется следующими данными:  
  ФИО, номером паспорта, контактным телефоном.

- **Объект недвижимости (`Property`)** — эта сущность характеризуется следующими данными:  
  типом, назначением, кадастровым номером, адресом, этажностью, общей площадью, числом комнат, высотой потолков, этажом расположения, наличием обременений.

- **Заявка (`Request`)** — эта сущность характеризуется следующими данными:  
  контрагентом, объектом недвижимости, типом заявки (покупка/продажа), денежной суммой.  
  Используется в качестве контракта.

### Используемые перечисления (`enum`):

- **`PropertyType`** — тип объекта недвижимости:  
  `Apartment`, `House`, `Office`, `Warehouse`, `LandPlot`, `CommercialSpace`.

- **`Purpose`** — назначение объекта недвижимости:  
  `Residential`, `Commercial`, `Industrial`, `Agricultural`, `MixedUse`.

- **`RequestType`** — тип заявки:  
  `Purchase`, `Sale`.

---

### 1. Модель данных

Создана полная объектная модель с использованием современных возможностей C#:
- Все обязательные свойства помечены как `required`.
- Поддержка XML-документации на английском языке.
- Чёткое разделение на доменный слой и тесты.

---

### 2. Тестовые данные

Создан класс **`RealtorAgencyFixture`**, содержащий:
- 10 клиентов (с русскими ФИО, паспортами и телефонами)
- 10 объекта недвижимости
- 10 заявок 
---

### 3. Unit-тесты

Реализованы все требуемые тесты:

- **`GetSellersInPeriod_ReturnsCorrectSellers`** — тест для вывода всех продавцов, оставивших заявки за заданный период.
- **`GetTop5ClientsByRequestCount_SeparateByType_ReturnsCorrectTop`** — тест для вывода топ-5 клиентов по количеству заявок (отдельно на покупку и продажу).
- **`GetRequestCountByPropertyType_ReturnsCorrectCounts`** — тест для вывода информации о количестве заявок по каждому типу недвижимости.
- **`GetClientsWithMinAmountRequest_ReturnsCorrectClients`** — тест для вывода информации о клиентах, открывших заявки с минимальной стоимостью.
- **`GetClientsSearchingForPropertyType_OrderedByName_ReturnsCorrectList`** — тест для вывода сведений о всех клиентах, ищущих недвижимость заданного типа, упорядоченных по ФИО.

#### RabbitMQ
Реализует асинхронную обработку сообщений через RabbitMQ с использованием двух компонентов:

Producer (RabbitMqProducer.cs) — фоновый сервис, который генерирует контракты запросов с помощью Generator и отправляет их в RabbitMQ канал. По умолчанию отправляет случайный контракт каждые 0.1 секунды. Запускается как Background Service в AppHost.

Consumer (RabbitMQConsumer.cs) — компонент, который подписывается на RabbitMQ канал, получает контракты запросов, десериализует их и сохраняет в базу данных.
